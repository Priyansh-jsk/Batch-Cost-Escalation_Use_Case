# Batch-Cost-Escalation_Use_Case

Problem Statement: You are provided with historical manufacturing data covering production batches, and supplier quality. The business wants to identify and predict the severity of cost escalation for each production batch so that preventive actions can be taken early.

**Target Variable:** Cost_Escalation_Level

**Data Provided**

**production_batches.csv** – Batch‑level manufacturing data capturing production details, process metrics, and the target cost escalation category.

**supplier_quality.csv** – Monthly supplier performance metrics by product category, describing quality, delivery reliability, and risk.

**Evaluation Criteria:**

1.Data Manipulation in R/Python

2.Descriptive & Inferential Statistics (with visualization wherever feasible)

3.Model Building 

4.Model Interpretation 

a.Technical Interpretation 
b.Business Interpretation 

5.Showcase: 
a.Flow of the model
b.Result validation of the model 
c.How do you ensure the best model has been selected? 
d.How do you ensure stability & predictability?
